# OS Mockup

## Compilation

Compile the source code using [CMake](https://cmake.org/) (platform independent):

```shell
cmake -S . -B ./build -DCMAKE_CXX_STANDARD=20
cmake --build ./build --target os-mockup
```

## Usage

```sh
./bin/os-mockup
```
