# CSOPESY Major Outputs

## Compilation

Compile the source codes of all projects using [CMake](https://cmake.org/) (platform independent):

```shell
cmake -B ./build
cmake --build ./build
```

## Usage

### MO1 - Process Scheduler

The source code for this project is located at [`./mco1`](./mco1). The last commit before submission is tagged by
[`mco1-submission`](https://github.com/seoyunnie/csopesy-mcos/tree/mo1-submission).

```sh
cd ./bin
./process-scheduler
```
